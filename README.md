# 赤峰 3D 沙盘 · 可交互三维全景

以 low-poly 艺术沙盘呈现内蒙古赤峰市全域：地形、水系、十二旗县区与廿二处胜景。  
参考 `example` 中「数字西湖」的交互三维沙盘思路，适配移动端，支持**分级 / 分地区 / 景点**浏览。

## 打开方式

- 直接用 **Chrome / Edge** 打开 `index.html`（Three.js 已内嵌，可离线）
- 或本地起服务：`npx serve .` / `python -m http.server 8080`

## 功能

| 能力 | 说明 |
| --- | --- |
| 分级 | 全市 → 旗县 → 景点，面包屑与飞行镜头 |
| 分地区 | 12 旗县区列表 / 点选地图旗县，聚焦与筛选 |
| 景点 | 22 处，按类别筛选，点击飞抵 + 详情卡 + 近景/环绕 |
| 移动端 | 底部抽屉列表、触控旋转缩放、safe-area |
| 主题 | 晴昼 / 日落 / 夜游 |
| 工具 | 全景、环绕、漫游、俯视、拍照 PNG、全屏 |
| 地形 | 区域高度场（兴安岭、沙地、河谷、湖盆）+ 聚落/植被 |

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动 / 双指拖动 | 旋转 |
| 滚轮 / 双指捏合 | 缩放 |
| 右键拖动 / 双指平移 | 平移 |
| 点击旗县或景点 | 飞行抵达并打开卡片 |
| 左侧/底部列表 | 分地区、景点直达 |
| `H` | 回到全市全景 |
| `U` | 显示/隐藏界面 |

## 目录

```
index.html          界面骨架
css/style.css       样式（含移动端）
js/boundaries.js    旗县边界（GeoJSON 简化）
js/data.js          投影、水系、山峰、城镇、景点
js/terrain.js       高度场
js/world.js         Three.js 世界构建
js/ui.js            列表 / 详情 / 分级
js/app.js           主题、飞行、交互、主循环
lib/                three.min.js + OrbitControls
data/               原始赤峰 GeoJSON
docs/               设计说明
```

## 说明

- 地理布局经艺术化压缩，**非测绘级地图**；景点信息据公开资料整理。
- 支持桌面与手机浏览器；建议开启硬件加速。
