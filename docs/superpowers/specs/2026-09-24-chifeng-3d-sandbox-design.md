# 赤峰 3D 沙盘设计

## 目标

参考 `example` 中数字西湖（seed-westlake）的 low-poly 可交互三维沙盘，制作**赤峰市**版本：

- 尽量精细的地形、水系、旗县、聚落与景点
- 支持移动端
- 支持分级浏览（全市 → 旗县 → 景点）、分地区筛选、景点导航
- 全部功能验证通过后上传 GitHub

## 技术选型

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| A. Three.js 离线单页（同 seed-westlake） | 双击可开、无构建、艺术化沙盘 | **采用** |
| B. Cesium 真实地球 | 测绘级、重、需 token | 否 |
| C. MapLibre + terrain | 地图向，沙盘感弱 | 否 |

选 A：与 example 同构、KISS、移动端可用、GitHub Pages 友好。

## 架构

```
index.html          UI 骨架（开场 / 列表 / 详情 / 工具栏）
css/style.css       米白·黛绿配色 + 移动端适配
js/boundaries.js    12 旗县区边界（由 GeoJSON 简化）
js/data.js          投影、水系、山峰、城镇、景点、文案
js/terrain.js       高度场生成（区域地貌 + 噪声）
js/world.js         Three.js 场景构建（地形/水/旗县/城镇/地标）
js/ui.js            列表、详情卡、筛选、分级、小地图
js/app.js           初始化、主题、交互、飞行、主循环
lib/                three.min.js + OrbitControls（离线）
```

## 空间模型

- WGS84 经纬度 → 平面投影（`SCALE_LON=170`, `SCALE_LAT=230`），原点约在市域中心
- 高程垂直夸张 `0.035` 世界单位/米，主峰约 70 单位
- 地形网格约 220×220，顶点着色 + flat shading 低多边形风

## 地貌高度场

按真实地势叠加：

1. 西北高、东南低的基底（大兴安岭南段 → 老哈河谷）
2. 山脉：大兴安岭南段、七老图山/燕山北麓、黄岗梁等主峰
3. 沙地噪声：浑善达克沙地、科尔沁沙地边缘
4. 河谷下切：西拉木伦河、老哈河、英金河、教来河
5. 湖盆：达里诺尔及周边洼地
6. 城镇台地压平：红山/松山中心区

## 分级与地区

- **L0 全市**：旗县色块、山脉、河流、市域轮廓，旗县名标签
- **L1 旗县**：聚焦该旗县，显示其景点列表与介绍
- **L2 景点**：相机飞抵，详情卡 + 近景/环绕

分地区：左栏/底栏按 12 旗县区筛选；景点再按类别（自然/地质/历史/草原沙漠/休闲）筛选。

## 移动端

- `≤768px`：侧栏改底部抽屉，详情卡底部卡片，工具栏变图标条
- 支持双指缩放/拖拽（OrbitControls）、点选飞抵、44px 触控目标
- `safe-area-inset`、禁止误滚、像素比上限 2

## 交互

- 拖拽旋转 / 滚轮或双指缩放 / 右键平移
- 点击旗县 → L1；点击景点或列表 → 飞行 L2
- 面包屑回退；H 全景；工具栏：全景/俯视/列表/主题/拍照/全屏
- 昼 / 暮 / 夜 三时主题；标签随距离显隐（LOD）

## 数据

- 边界：`data/chifeng_full.json`（12 旗县区 MultiPolygon）
- 景点约 22 处（人文地理公开知识整理），含坐标、类别、简介
- 水系/山峰/城镇为艺术化示意，非测绘级

## 验收

1. 桌面与移动视口可打开、可交互
2. 12 旗县可点击/筛选并飞行
3. 全部景点可列表直达 + 点选飞抵 + 详情
4. 三时主题、俯视、拍照可用
5. 无控制台报错；构建资源可离线打开
